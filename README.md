# Among-Us-Random-Language
Among Usの言語をUIごとに完全ランダムにします。<br>
※ このMODの作成には**一部AIが使用されています**。<br>
## 注意！
### 下の画像にはMod Stampがありませんが、しっかりとdll(MOD)にはMod Stampが導入されています。<br>
### また、PlayerNameを隠す機能はこのMODには搭載されていません。<br>探している方は、→[こちらのMODを使用してください。](https://github.com/mitsuya-new/AmongUs-PlayerName-Mask)
